Build a responsive, cinematic filmography page for a fictional director named Leon Vasari. This is a recreation brief written for Frontend Frames; the visual inspiration is credited to MotionSites AI (https://motionsites.ai/).

Create a warm paper-colored artboard with small editorial navigation, a centered blue Japanese/English director mark, decade filters, and a full-width horizontal shelf of worn VHS tapes. Use an intentionally tactile 1970s/1980s archive feel. The tapes should have varied spine colors and original fictional titles. Put the currently selected tape in front of the shelf, angled enough to reveal its front cover. Keep the active title, genre, and year legible below the shelf; never stack multiple captions on top of each other.

Implement real interactions: selecting a tape, previous/next arrows, decade filtering, drag or wheel shelf browsing, keyboard left/right navigation, Enter to inspect, and Escape to close. A selected tape opens a film detail view with a fictional synopsis and a clear message if no stream exists. Keep controls visible and tappable on mobile, preserve focus behavior, and respect reduced motion. Use responsive dimensions so the shelf remains usable from a 360px phone to a wide desktop.

Use semantic HTML, CSS, and small vanilla JavaScript. Make the layout self-contained, fast, accessible, and suitable for static hosting. Add a back link to the Frontend Frames collection. Any original design artwork must be used only when properly licensed or provided by the site owner; otherwise create distinct original artwork.
